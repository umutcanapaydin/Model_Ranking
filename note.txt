THE ONE THING A NEW AGENT MUST NOT UNDO
`f"file:{path}?mode=ro"` DOES NOT open a database read-only. Four path shapes defeat it and all
four write into the real file (`?mode=rwc&z=`, `#`, `?`, `?vfs=unix&mode=rwc&j=`). Call
`app.workflows.schema.open_readonly`. `tests/unit/test_readonly_uri.py` fails any `file:`-prefixed
f-string in `src/` or `scripts/`. This fix was already made once, in `adapter/main.py` at M6, and a
module written three milestones later rebuilt the bug anyway — under a comment defending it.
**A fix that lives in one module is not a fix** (W-052).
