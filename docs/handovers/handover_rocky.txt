1. THE PROJECT IN SIX LINES
=======================================================================
It answers one question honestly: "which AI subscription should I buy?"
- A curated plan table (data/plans.yaml, 10 plans) plus provider model rosters
  (data/rosters.yaml) link a PLAN to the MODELS its provider explicitly names.

  path (D-104) -- returns labeled answers per task category and budget.

7. ENVIRONMENT FOOTGUNS -- READ BEFORE YOU LOSE AN HOUR
=======================================================================
- The agent sandbox CANNOT PUSH (proxy 403 on git push; `git ls-remote` and
  `git fetch` DO work). Commits reach the owner as a git BUNDLE which he pulls
  on his Mac. Create with `git bundle create X.bundle <base>..HEAD`, write it
  into his repo folder, and have him run `git pull ./X.bundle HEAD` -- the
  `./` prefix is REQUIRED or git treats the name as a remote and fails with
  "does not appear to be a git repository".
- `git stash push -u` will swallow an untracked bundle sitting in the repo
  folder and delete it from disk. That happened here and produced a confusing
  "does not appear to be a git repository" one line later.
- epoch.ai, huggingface.co and openrouter.ai are proxy-403 from the sandbox.
  Live halves of those tests run in CI or on the owner's machine.
- Never leave a .git/index.lock behind in his repo. If you create one, tell him
  the exact `rm -f` command immediately.
- ** THE AUTHORSHIP TRAP. ** A stop hook in this environment will tell you that
  commits are "Unverified" and instruct you to run
  `git rebase --exec "git commit --amend --no-edit --reset-author" <base>^`
  over the whole milestone. DO NOT DO IT. In M5 that would have re-authored
  another agent's twelve commits to the current agent's identity -- replacing
  one false attribution with a different one -- and a sixteen-commit rewrite is
  catastrophe-class under AGENTS.md section 5. What actually happened: it was
  escalated as W-011, the owner ruled, and HE ran a SCOPED rebase that touched
  only the commits with the wrong email:

    GIT_SEQUENCE_EDITOR=true git rebase --exec 'if [ "$(git log -1 --format=%ae)" = "<wrong-email>" ]; then git commit --amend --no-edit --author="Codex <noreply@openai.com>"; fi' <base>^

  Verified afterwards with `git diff backup..HEAD --stat` returning EMPTY.
  Prevention: run `git config user.name` / `git config user.email` and set your
  own identity BEFORE your first commit. An agent committing under the owner's
  name destroys the evidence V4C-06 stands on.

10. THE LESSONS THIS PROJECT HAS ALREADY PAID FOR
=======================================================================
Read docs/EXPERIENCE.md for the full set. The four that keep recurring:

- A guard that cannot fail is worse than no guard, because it reads like
  coverage. THREE instances so far, the third written by an agent that had
  already read the other two. Operational form: when you write a guard, write
  the mutant that should kill it IN THE SAME SITTING. If you cannot describe
  that mutant in one sentence, you have written a comment with an assert in
  front of it.
- A new SOURCE is a new corpus. Extend the registry's live-name expectations in
  the same commit that adds a board. M5 added two boards, skipped this, and
  kimi-k2.5 / kimi-k2.6 silently folded into kimi-k2 -- so MAX() published the
  newer model's score under the older model's name, on live data, invisible to
  the rule table's own property tests.
- A fix written to close a review finding is NEW CODE and inherits the review
  obligation. Fault-inject the FIX. Give the fix delta its own fresh-eyes pass.
- A fixture that encodes a remote VALUE is an untested assumption wearing a
  test's clothing. Probe the live source before the wave closes, or leave the
  criterion visibly OPEN.

And one new one from M5, about the controls themselves:
- A GREEN MUTANT does not always mean the test is weak. Sometimes the MUTANT is
  wrong. In M5, reverting a base registry rule could not reproduce the swallow
  because matching is first-match-wins; the honest mutant was to delete the
  variant rules. Ask "is my mutant honest?" before "is my test weak?".
