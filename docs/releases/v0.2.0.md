## What changed

- The Mac no longer runs an engine: the hosted engine is the only one, refreshed and deployed each night by the
  owner's workflow (#427, D-222, D-224)
- A night that never finishes says which source it was reading, and every night records each source's seconds
  (#426)
- One source's bad file no longer stops the night: a deep or 4,300-digit JSON fails that source only (#411), and
  SimpleBench's and the bracket reader's regexes are linear (#412, #417)
- An image or audio variant named in brackets, `GPT-4o (image)`, is no longer read as the text model (#419); a
  media board model that carries a per-token price is named in the night's drift (#403)
- An accepted cut excuses a row by its own name, expires within 30 days, and names an ADR that names its board;
  Epoch's chess cut is retired (#418, #429, D-221, D-223)
- The deploy gate's DevFlow exemption reads its pin at the protected base and ignores replace refs; the deploy
  scripts are safety surface (#410, D-223)
- The plan prices were re-verified on 2026-10-25 (unchanged), and Perplexity's Pro and Max model lists follow its
  2026-10-17 table (#450)
- Process: client-decls refuses three more ways to rebuild a served number (#396); tests hold the OSWorld reader
  (#404) and the record schema (#413); the memory-ceiling test measures its baseline (#408); four deploy
  spellings are refused on the record (#401, R-4); the PRD gate reads every ADR id (#447); CI runs the suite in
  parallel with a 30-minute limit (#406, #424)
