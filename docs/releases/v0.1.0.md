# Release v0.1.0 — 2026-10-23

**Build:** main's tip once `release/v0.1.0` merges -- the git SHA the hosted engine's `/health` reports as
`build` after `scripts/deploy_hosted_engine.sh` · **Target:** the hosted engine on Fly.io
(`https://model-ranking.fly.dev`) and the Mac's launchd engine (D-170, D-185)

The first release with a tag. The two before it (`3426ff3..81af5ba`, `81af5ba..958458d`) shipped on their
review verdicts alone; this record covers `958458d..660af4b`.

## What changed

- `agentic-coding` ranks on Datacurve's public DeepSWE leaderboard (CC BY 4.0), with no Hugging Face
  token (#265, D-216)
- Every board now reads its publisher's licensed or permitted data; the stale Epoch WebDev board and
  the OpenRouter price copies are gone (#265, #376, D-215)
- New external boards, each licence-checked first, among them LiveBench 2.0 and SimpleBench (#379)
- Mathematics has a second board, Epoch's math_level_5 (#377)
- Five image and video surfaces (image_edit, text_to_image, image_to_video, text_to_video, video_edit)
  rank on quality only, and a request to make one reaches its board (#378, #405, D-218)
- The app: Apple Intelligence reads every question, beside its nearest labelled examples, prewarmed when
  the question field gains focus (#351, #353, #354, #361); routing fixes for a Turkish "yapay zeka"
  question, plain questions sent to mathematics, a science myth, and an agent that writes code (#292,
  #293, #294, #295)
- The app's kept answers file uses complete file protection and refuse a file over 8 MiB
  (#314, #323)
- The serving image trusts certifi 2026.10.19, without the compromised CA root (#367)
- The nightly refresh and deploy can run off the Mac (#387, #389, #391, D-217); it runs only once the
  owner installs the workflow and the `fly-production` environment (`docs/owner-actions.md`)
- Process: the Bash guard, the deploy gate and the client-decls gate were hardened (#242, #255, #256,
  #282-#287, #305, #317-#321, #344, #363, #371, #373, #374, #390, #392, #400); no user sees these
